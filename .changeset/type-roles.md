Type roles: thirteen new text utilities that each set size and line height together. They are `text-display-2xl`, `text-display-xl`, `text-headline-large|medium|small`, `text-title-large|default|small`, `text-body-large|default|small` and `text-label-large|default`, and they mirror the Figma text styles. New size tokens `--font-size-text-3xl|4xl|5xl` (30, 36 and 48px), with matching line heights. `cn()` merges the role classes correctly next to text colours.
